## 最终交付范围

1. 发现卡统一为 3:4 竖图紧凑布局；“下回吃”位于图片正下方，不遮挡照片；保留明确的未收藏/已收藏文字状态。
2. 展示当前三级小碗推荐、全部非零“好在哪儿”计数、历史“适合”场景，以及最多两道推荐菜预览与剩余数量。
3. 首页发现列表取消 3 家截断，按最近活动排序并完整纵向展示所有有效地点；服务器读取不再限制为前 100 条。
4. 搜索覆盖餐厅、地址、菜系、推荐菜和历史场景；地点筛选支持行政区精确匹配、商圈 3 公里与地铁 1.5 公里半径。
5. 三个筛选浮层保持单开，支持切换、点击外部、Escape 和选择后关闭，并同步 `aria-expanded`。
6. 发现卡与详情页共享城市/行政区格式清理；商圈只读取高德缓存，缺失时隐藏，不猜测名称。
7. 商圈缓存支持新地点即时尝试、历史地点分批补齐、临时失败退避重试和未命中状态。
8. 高德 Edge Function 增加严格 UUID、返回结构与 upsert 错误处理，并继续只允许完整精确 Origin。
9. V1.3 到访记录、当前观点、照片、隐私治理与 Owner 成员目录基础随同 PR #12 一并发布。

## 合并后人工冒烟检查

在正式域名完成以下最小检查即可关闭 V1.3.1：

1. 登录后首页能看到完整地点列表并滚动到第四家及后续地点。
2. 任一地点的“下回吃”可添加、移除并在刷新后保持。
3. 完成一次站内搜索与筛选清除。
4. 使用现有生产 Origin 验证一次高德地点建议或地图视图。
5. 检查至少一个已有商圈缓存的地点，以及一个无商圈时的隐藏降级。

## 回滚原则

- 前端可在 Vercel 回滚至上一生产部署。
- Edge Function 可回滚至上一版本；缓存数据保留但不会影响旧前端。
- migration 为向前兼容的新增表、类型、策略和 RPC，紧急回滚不删除数据库对象。
- 商圈服务异常时允许降级隐藏商圈，城市、行政区、站内搜索、详情页和记一顿继续工作。
