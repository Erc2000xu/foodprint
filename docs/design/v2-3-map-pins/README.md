## 评审边界

本轮只评审：默认 Pin、选中 Pin、聚合点的造型、品牌感、地图辨识度与密集状态表现。

图中的手机外壳、地图、照片、英文占位文字、营业状态、距离、价格或评分只用于营造真实使用场景，不构成 Foodprint 产品规则、正式文案或最终 UI。正式实现仍以 V2.3 产品规格和技术交接为准。

## 选择结论

- 产品负责人选择 B「餐盘定位圆章」。
- 正式版本保留 B 的圆形餐盘、短定位尖角和暖米白 / 深青绿基调。
- 中心图形改为专门为地图小尺寸重绘的 1 / 2 / 3 层小碗，分别对应“值得去 / 想再去 / 会专门去”。
- 选中态采用放大 + 橙红外圈 / 尖角，避免只靠颜色。
- 聚合沿用同一餐盘外形，数字由程序动态绘制；用户位置使用独立蓝色圆点。

正式生产 SVG、工程注册表、交互状态、尺寸锚点和 QA 证据均收录在 [`final/README.md`](./final/README.md)。

## 选定后的制作门槛

1. 先把所选方向重绘为确定性的 SVG / CSS，不直接裁切 ImageGen 图片上线。
2. 形成默认、选中、按下、聚合、键盘焦点、减少动态效果六类状态。
3. 输出 24 / 28 / 32 / 40 / 48px 小尺寸 QA 板，并验证 1× / 2× / 3×。
4. 在高德远山黛、月光银、草色青、马卡龙四套官方底图上比较；V2.3 默认仍优先远山黛。
5. 在 320 / 390 / 430px、疏散 / 密集点位、底部抽屉四档高度下验收。
6. 聚合点数字验证 2、9、12、99、100+；不能溢出或误认为单店推荐等级。
7. 选中状态不能只靠颜色，需同时改变尺寸、描边或轮廓。
8. 正式资产已经确认并制作；动态地图组件接入和真实高德底图验收完成后，再把 `VISUAL_ASSET_REGISTRY.md` 中 IC-08 更新为已接入 / 已验收。

## 生成方式

本轮五张方向稿使用 Codex 内置 ImageGen 生成。共同约束：远山黛风格浅色底图、深青绿 / 暖米白 / 鼠尾草绿 / 橙红品牌色、同一组默认 / 选中 / 聚合状态与地图实景对比。每张采用独立提示词，以确保方向之间存在真实造型差异。
