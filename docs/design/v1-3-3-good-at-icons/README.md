## 共同语义

| slug | 名称 | 图形语义 |
| --- | --- | --- |
| `tasty` | 吃得香 | 筷子夹起一口食物 / 香气 |
| `comfortable` | 坐得住 | 舒适餐椅 |
| `good_for_chat` | 聊得开 | 两个对话气泡 |
| `good_value` | 花得值 | 硬币与确认标记 |

“花得值”不用货币符号或纸币，避免将其误解为“便宜”；它表达的是价格与体验相称。

## A｜同款花边奖章

文件：`direction-a-scalloped-medals.png`

- 与现有小碗奖章最像，品牌一致性最强。
- 大尺寸选择卡中精致、完整。
- 风险：推荐强度和体验维度都使用花边奖章，可能让用户误以为它们是同一层级的评分；16–20px 时外框会挤压内部图形。

## B｜极简餐桌线稿

文件：`direction-b-minimal-table-lines.png`

- 小尺寸识别最好，适合发现卡的“图标 + 文字 + 人数”。
- 可通过 CSS/SVG 控制颜色、选中态和不可用态。
- 与小碗奖章形成清楚分工：小碗是推荐等级徽章，线稿是体验维度。
- 风险：单独展示时品牌感稍弱，需要靠统一线宽、橙色小细节和文字排版补足。

## C｜四彩陶瓷小章

文件：`direction-c-ceramic-tiles.png`

- 最适合 C 版记一顿的 2 × 2 大选择卡。
- 四个受控颜色帮助快速记忆，也与已有视觉台账中的四色方向一致。
- 风险：24px 以下瓷砖外框和内部线条会同时变细；发现卡中可能显得像四个小应用图标。

## D｜温暖餐桌物件

文件：`direction-d-warm-table-objects.png`

- 生活感和食物温度最强，视觉亲和力高。
- 已确认为正式方向。
- 正式独立资产放大主体、移除外部阴影并简化细节，保留温暖材质感。
- 适用于记一顿的大选择卡，也通过 256px 程序版服务发现卡、地点详情和饭后聊。

## E｜食迹小印章

文件：`direction-e-foodprint-stamps.png`

- 对比度最高，在照片或复杂背景上仍容易识别。
- 选中态、反白态和深色底适配方便。
- 风险：视觉重量较大；四枚同时出现时容易压过地点名称、推荐小碗和人数信息，更适合未来 V3 的强调标签。

## 正式制作与 QA 记录

- 使用内置 ImageGen，分别以 D 方向板和现有小碗为视觉参照生成四个独立源图。
- 源图使用纯色 `#FF00FF` 背景；通过项目图像技能的去底工具生成透明 RGBA PNG。
- 四张母稿均为 1254 × 1254；四张程序版均为 256 × 256。
- 非透明主体覆盖率：
  - 吃得香：约 78.5% 宽 × 84.1% 高；
  - 坐得住：约 59.2% 宽 × 85.9% 高，受椅子自然纵向比例限制；
  - 聊得开：约 86.9% 宽 × 58.4% 高；
  - 花得值：约 82.3% 宽 × 76.1% 高。
- 非透明区域未检测到残留洋红色像素。
- `production/qa-size-preview.png` 已对米白、浅鼠尾草和深青背景上的 128/64/32/24px 表现进行检查。
- 米白、白色和浅鼠尾草背景通过；深青实心背景会降低椅架对比度，因此不作为选中态。

## V1.3.3 接入规则

1. 建立唯一 `GoodAtIcon` 组件；各页面按 slug 调用 `*-ui.png`，禁止复制路径或自行换图。
2. 记一顿选择卡使用 56px，320px 下不小于 48px。
3. 发现卡使用 28–32px；地点详情建议 36px；饭后聊不小于 28px。
4. 选中态使用浅鼠尾草底、深青边框和勾选标记，不能只靠颜色。
5. 图标必须配文字或可访问名称，不能单独承担完整含义。
6. 新增任何使用位置后同步更新 `docs/VISUAL_ASSET_REGISTRY.md`。
