# 食迹 Foodprint｜产品总览

> 生效日期：2026-07-28
> 状态：当前产品基线（长期内容变更须记录原因）

## 1. 产品是什么

Foodprint 是一个邀请制、由朋友共同维护的餐饮地点地图。它记录真实到访后的体验、评分、照片与推荐，并帮助小组成员回看、分享和发现值得去的餐厅。

它不是开放式餐厅黄页、POI 抓取库，也不以收集用户实时位置为目标。

## 2. 核心用户与价值

| 用户 | 需要完成的事 | Foodprint 提供的价值 |
| --- | --- | --- |
| Member | 记录吃过且愿意推荐的地点；找朋友真实推荐 | 可信、私密、可回看的美食记忆 |
| Admin | 协助维护邀请与地点信息 | 轻量的小组运营能力 |
| Owner | 创建并治理共同小组，保障数据与成员安全 | 可控的共同空间与数据所有权 |

## 3. 产品原则

1. **真实体验优先**：共同地点以真实到访和体验为基础；“想去”不等同于推荐。
2. **朋友小组优先**：先服务小范围、高信任关系，而非公共流量与泛化内容。
3. **隐私与权限先于便利**：不公开私有照片、邮箱、精确实时位置或签名链接；服务端与 RLS 共同保障权限。
4. **地理数据合规且可替换**：高德只在免费许可、用途和配额允许范围内使用；不得批量抓取、再分发或自动付费。
5. **小步交付、可验收、可恢复**：每项重要能力都必须有明确范围、验收口径、迁移与回滚方案。

## 4. 当前产品基线

**当前生产版本：V1.1.1（2026-07-28 人工验收通过，体验优化观察中）**

- 邀请制注册、共同小组、Owner / Admin / Member 权限；
- 高德地点搜索、真实体验标记、共同地点与详情；
- 列表优先的共同地图浏览、结构化筛选与高德导航；
- 想去、动态、私有照片、PWA、数据导出；
- 邀请链接加密持久化、成员治理与成员目录隐私控制。

当前地图是静态地图图片与列表的组合，而非交互式地图；这是一项已知产品限制，不应描述为已实现的互动地图能力。

## 5. 不变约束

- 当前运行：Vercel + Supabase + 高德；备案完成前不切换腾讯云和正式 `.com.cn` 域名。
- 数据库、RLS、RPC 变更只新增向前兼容的 Supabase migration，不修改已上线 migration。
- 密钥与生产凭据不得进入 Git；高德 Web Service Key 仅留在受控服务端 Secret。
- 生产恢复采用应用回退和向前修复 migration，不在生产执行破坏性数据库回滚。

详细技术、运行和高德政策分别见 `OPERATIONS.md`、`AMAP_FREE_TIER_POLICY.md` 与 `PROJECT_CONTEXT.md`。

## 6. 文档优先级

发生冲突时，按以下顺序判断：

1. 项目负责人最新明确决定；
2. 已批准的版本 Spec；
3. 本文的长期产品基线；
4. `ROADMAP.md` 的方向和排序；
5. 发布交接、实现细节和历史文档。

路线图是方向，不是功能承诺。进入开发前，每个版本都必须形成独立 Spec。
