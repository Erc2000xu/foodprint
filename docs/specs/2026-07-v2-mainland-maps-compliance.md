# V2｜大陆部署、地图体验与私域运营

> 状态：V2-A 已发布，进入稳定期；动态地图与 V2-B 数据平面迁移另行推进
> 进入条件：ICP 备案已完成；V1 当前主路径稳定；迁移演练通过（已满足）
> 目标：安全切换腾讯云与 `foodprint.com.cn`，保持邀请制私域美食记录的产品边界。
> 实施唯一交接：[V2 大陆域名与腾讯云迁移开发交接](../FOODPRINT_V2_MAINLAND_DOMAIN_MIGRATION_DEVELOPMENT_HANDOFF_2026-08-05.md)

> V2.3 更新（2026-08-12）：动态地图的默认入口、数据范围与降级方式已由 [V2.3 产品规格](./2026-08-v2-3-dynamic-discovery-map.md) 和 [V2.3 ADR](../decisions/2026-08-12-v2-3-dynamic-map-default-and-list-fallback.md) 取代本文件早期设想。若有冲突，以 V2.3 为准。

## 1. 范围

### 包含

- 腾讯云部署、DNS/TLS、稳定域名、灰度切流和可回退方案。
- 应用 URL、Auth Redirect URL、Cookie/Origin、图片存储、环境变量、PWA 与回调 URL 的迁移核对。
- 受控邀请、成员角色、私有内容访问、审计可见性与网络安全的工程收口。
- 高德动态地图与列表联动、点位聚合、地点详情卡片和当前视野地点抽屉；它们不阻塞已经完成的域名迁移，并在 V2.3 独立开发。

### 不包含

- 未经验证的公开化、评论互动、商家体系、广告和付费流量。
- 将当前 Supabase 数据库、Auth、Storage 或 Edge Functions 自动迁为腾讯云原生后端；该工作需另立 V2-B。
- 自动购买地图服务或超许可的 POI 抓取/再分发。

## 2. 动态地图体验

- 发现页可在动态地图与列表间切换；V2.3 默认以动态地图为主，列表是平级视图和地图故障时的唯一降级。
- 只渲染当前小组已推荐地点；去试试与 dismissed 地点不出现在地图。
- 支持拖拽、缩放、点按、聚合、当前视野地点抽屉、地点小卡和跳转详情。
- 地图与完整列表必须使用同一组授权数据；地图视窗只决定抽屉子集，不触发公开 POI 搜索。
- 地图加载失败、弱网、配置或供应商故障时自动回到完整列表；不再显示或调用静态地图。
- 不主动采集或长期保存用户实时位置。若提供“定位到我附近”，须单次授权、明确说明、即时使用、不入库，并提供不授权路径。

## 3. 迁移顺序

1. 准备腾讯云预发环境，完成构建、健康检查、日志、备份、限流和最小权限访问。
2. 收口邀请制：关闭公开注册、命名邀请、角色/RLS/审计权限回归测试。
3. 同步 Supabase Auth、Storage CORS（如实际需要）、Edge Function `APP_ALLOWED_ORIGINS`、高德 Key 白名单、服务器环境变量和 PWA/回调配置。
4. 对新域名进行功能、安全、性能和真机验收；保留 Vercel 可回退路径。
5. 低风险灰度切流，监控认证、搜索、图片、地图、错误率和性能；在预设窗口内可切回旧环境。
6. 稳定期结束后再下线旧入口，并完成迁移记录和灾备演练。

## 4. 安全与合规发布门槛

- 发布前按 SECURITY_COMPLIANCE_BASELINE.md 完成数据流、最小化、隐私政策、账户删除、访问控制、日志和事故响应检查。
- 产品默认私域：无公开注册、无公开内容入口、无通用多人邀请链接；邀请、角色、RLS、Storage 和导出必须在后端共同执行。
- 高德使用继续遵守其 Key、域名、免费额度和数据使用规则；迁移后所有新域名重新加入准确白名单。
- 对用户照片、昵称、到访日期、地点和文字建立最小必要的告知、删除和访问边界。

## 5. 验收标准

- 新 .com.cn 域名 HTTPS、DNS、认证、图片、地点搜索、动态地图、导航和 PWA 主路径正常；V2.3 不再要求静态地图。
- 地图仅显示授权小组的正向推荐地点；无定位授权时核心体验完整可用。
- 腾讯云故障、地图故障、认证回调错误都有监控、可理解降级和书面回滚步骤。
- 切流前后数据完整性、RLS、备份恢复和灾备演练记录通过。
- 合规和安全发布清单、第三方配置清单、负责人和复核日期全部归档。
