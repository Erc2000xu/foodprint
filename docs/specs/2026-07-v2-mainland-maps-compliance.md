# V2｜大陆部署、地图体验与合规运营

> 状态：待立项
> 进入条件：ICP 备案完成；V1.3 稳定；迁移、隐私与安全评审完成
> 目标：安全切换腾讯云与大陆 .com.cn 域名，在稳定、合规的前提下升级动态/静态地图体验。

## 1. 范围

### 包含

- 腾讯云部署、DNS/TLS、稳定域名、灰度切流和可回退方案。
- 高德动态地图与列表联动、静态地图降级、点位聚合和地点详情入口。
- Auth Redirect URL、Cookie/Origin、图片存储、环境变量、PWA 与回调 URL 的迁移核对。
- 个人信息、数据安全、网络安全、第三方数据使用与日常运营的合规清单。

### 不包含

- 未经验证的公开化、评论互动、商家体系、广告和付费流量。
- 自动购买地图服务或超许可的 POI 抓取/再分发。

## 2. 动态地图体验

- 发现页可在列表与地图间切换；默认仍以列表为主，地图是可视化探索而不是唯一入口。
- 只渲染当前小组已推荐地点；去试试与 dismissed 地点不出现在地图。
- 支持点按、聚合、地图视窗刷新、地点小卡和跳转详情。
- 地图加载失败、权限拒绝、弱网和供应商故障时自动回到列表与静态地图占位，不阻断找店。
- 不主动采集或长期保存用户实时位置。若提供“定位到我附近”，须单次授权、明确说明、即时使用、不入库，并提供不授权路径。

## 3. 迁移顺序

1. ICP 备案实际完成，并确认域名、主体和服务范围可上线。
2. 准备腾讯云预发环境，完成构建、健康检查、日志、备份、WAF/限流和最小权限访问。
3. 同步 Supabase Auth、Storage CORS、Edge Function APP_ALLOWED_ORIGINS、高德 Key 白名单、服务器环境变量和 PWA/回调配置。
4. 对新域名进行功能、安全、性能和真机验收；保留 Vercel 可回退路径。
5. 低风险灰度切流，监控认证、搜索、图片、地图、错误率和性能；在预设窗口内可切回旧环境。
6. 稳定期结束后再下线旧入口，并完成迁移记录和灾备演练。

## 4. 安全与合规发布门槛

- 发布前按 SECURITY_COMPLIANCE_BASELINE.md 完成数据流、最小化、隐私政策、账户删除、访问控制、日志和事故响应检查。
- 由具备资格的法律/合规顾问根据实际主体、用户范围、是否商业化、数据存储区域和跨境处理情况确认 ICP 备案之外是否还需要其他许可、评估、协议或登记。本 Spec 不构成法律意见。
- 高德使用继续遵守其 Key、域名、免费额度和数据使用规则；迁移后所有新域名重新加入准确白名单。
- 对用户照片、昵称、到访日期、地点和文字建立最小必要的告知、删除和访问边界。

## 5. 验收标准

- 新 .com.cn 域名 HTTPS、DNS、认证、图片、地点搜索、静态/动态地图、导航和 PWA 主路径正常。
- 地图仅显示授权小组的正向推荐地点；无定位授权时核心体验完整可用。
- 腾讯云故障、地图故障、认证回调错误都有监控、可理解降级和书面回滚步骤。
- 切流前后数据完整性、RLS、备份恢复和灾备演练记录通过。
- 合规和安全发布清单、第三方配置清单、负责人和复核日期全部归档。
