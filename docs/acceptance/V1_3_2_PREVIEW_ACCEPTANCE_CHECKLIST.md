# V1.3.2 Preview 验收清单

> 验收前：完成本版本 Supabase migration 与 `amap-poi-search` Edge Function 部署，并从本分支生成 Vercel Preview。

## 去试试候选卡

- [ ] 打开“去试试”，候选卡显示地点名、市/区和地址；有高德缓存时显示商圈，无缓存时不显示空白商圈标签。
- [ ] 点击“导航去这里”，确认会在新页/高德中打开该地点导航；按钮有路线箭头 SVG 和文字。
- [ ] 创建者可编辑来源/期待或删除；其他成员没有编辑删除入口。

## 搜索与当前位置

- [ ] 普通关键词搜索在未授权定位时可正常返回地点。
- [ ] 仅点击“按当前位置找”才出现浏览器定位授权请求。
- [ ] 允许定位后再搜索：结果显示城市与距离，并按距离近到远排列。
- [ ] 拒绝定位后页面给出说明，普通搜索仍正常可用。

## 完整转正

- [ ] 选一条 pending 候选，点“我去过了”，勾选真实体验确认。
- [ ] 点“值得推荐，记下这顿”：跳转到预选该地点的完整记一顿表单，候选仍留在待尝试列表。
- [ ] 未填写必填项或故意使保存失败时，候选仍为 pending，发现中没有该地点。
- [ ] 完整填写并保存后：候选从去试试消失，发现出现地点，地点详情有首条到访记录、菜系、推荐强度和好在哪儿。
- [ ] 从“记一顿”直接搜索同一高德 POI 并完整保存，原 pending 候选同样消失。
- [ ] 对另一候选选“这次先不推荐”：候选消失，但发现、饭后聊均不出现负面内容。

## 分类与回归

- [ ] 新表单地点类型不再有“小吃 / 街头餐饮”，但仍有“小吃快餐 / 面食”菜系。
- [ ] 原来为 `street_food` 的地点仍可在发现、搜索和详情中正常显示，并显示为“餐厅”。
- [ ] 手机 320、375、390px 宽度下，导航、我去过了与编辑操作不会溢出或相互遮挡。
