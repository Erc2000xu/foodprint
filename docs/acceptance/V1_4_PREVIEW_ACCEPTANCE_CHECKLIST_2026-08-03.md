## 3. 验收准备

请使用 Preview 环境和测试共同地图，不要直接用生产账号执行删除、隐藏、下架、退出共同地图等操作。准备：

- 一个已验证邮箱、已加入共同地图的普通成员账号。
- 一个 Owner/Admin 测试账号。
- 测试共同地图中至少有一条已推荐地点、一条“去试试”候选和一条到访记录。
- 一张竖版照片和一张横版照片；如需验证限制，再准备超过 9 张图片。
- 浏览器 DevTools 的 Responsive Design Mode，分别检查 320、375、390 px 宽度。

每一项通过后勾选 `[x]`；若不通过，请记录路由、复现步骤、截图和浏览器版本。

## 4. 全局字体与文案

- [ ] 页面正文、导航、表单、地点名、地址、动态用户内容和管理页均使用功能字体“思源黑体 SC”。
- [ ] `/`、`/try`、`/mark` 起始态、`/activity` 各只有一条创意标题，并使用站酷小薇体：
  - `今天想去哪儿吃？`
  - `想去的地方，先记在这里。`
  - `把这一顿，好好记下来。`
  - `吃过以后，留下几句话。`
- [ ] 创意字体没有出现在按钮、输入框、地址、日期、错误、隐私说明、动态地点名、用户笔记或管理页。
- [ ] DevTools 的 Network 中两个字体请求来自 `/fonts/*.woff2`，没有运行时字体 CDN 请求。
- [ ] 页面上不出现第三方地图/地点服务品牌；地图合规版权行可保留 `© 高德地图`。
- [ ] 任何可见错误都没有出现 `Supabase`、`RPC`、`JWT`、`PGRST`、provider 原始错误或英文堆栈。

## 5. P01｜发现 `/`

- [ ] 标题、引导、搜索进行态和搜索说明分别为：`今天想去哪儿吃？`、`从朋友吃过的地方里，选一家合适的。`、`搜索中…`、`可搜餐厅、区域、商圈、地铁、菜系或推荐菜。`
- [ ] 站内搜索建议显示“菜系 / 地点”；地点建议显示“行政区 / 商圈 / 地铁”，不显示第三方品牌。
- [ ] “按地点找”显示“行政区”和“商圈 / 地铁”；说明为“搜索并选择一个地点；商圈按 3 公里、地铁按 1.5 公里筛选。”
- [ ] 选择排序“离我最近”时，定位成功、拒绝权限和浏览器不支持三种状态均可读；成功提示为“已按离你最近排序；位置仅用于本次排序。”
- [ ] 搜索结果计数为““关键词”找到 N 个地点”，普通结果计数为“朋友推荐了 N 个地点”。
- [ ] 无筛选结果显示“没有符合条件的地点 / 可以换个条件再试试。”；共同地图无地点显示“共同地图里还没有地点 / 先记下一家去过的地方。”。
- [ ] 地点卡无照片显示“暂无照片”，已保存按钮显示“已加入下回吃（点击移除）”，汇总使用“有 N 位朋友留过记录”，地铁标签使用“靠近 {地铁站}”。
- [ ] `/` 与 `/?view=map` 都能打开；阻断地图请求后显示“地图暂时无法显示；你仍可在列表中查找地点。”并可“重试地图”。

## 6. P02｜去试试 `/try`

- [ ] 标题和引导为“想去的地方，先记在这里。”以及“想去的地方先记在这里。亲自吃过并愿意推荐后，才会出现在发现；不推荐的选择不会公开。”
- [ ] 搜索、选择地点、补充“从哪里听说的（可选）”和“为什么想去（可选）”后可加入候选。
- [ ] 空结果显示“暂时没有找到这家。可以换个关键词再试试。”；空列表显示“还没有想去的地方 / 从朋友提过的一家开始。”。
- [ ] 候选卡来源显示“由 {昵称} 提出”；操作为“编辑 / 收起 / 移除这家”。
- [ ] 点击“我去过了”后，确认标题、后果说明、真实性确认和两个结果按钮与定稿一致；“暂不推荐”不会公开负面评价。
- [ ] 加入成功两种反馈分别为“已加入去试试。”和“这家已经在去试试列表中。”；验证移除反馈为“已从去试试移除；这次选择不会对外显示。”。
- [ ] 搜索失败、定位失败和重复候选均显示中文可操作提示，不显示服务原始错误。

## 7. P03｜记一顿 `/mark`

- [ ] 起始态标题为“把这一顿，好好记下来。”；引导、字段名、占位符和排序文案与定稿一致。
- [ ] 首次收录显示“收录新地点”、真实体验确认、主菜系、推荐强度和“好在哪儿（选 1–2 项）”；已有地点显示“已有朋友记录”。
- [ ] `P03-25` 占位符逐字为：`用逗号隔开，例如：手冲咖啡，巴斯克`。
- [ ] 图片说明为“上传前会压缩图片，并移除拍摄信息。”，处理态为“图片处理中…”，最多 9 张。
- [ ] 保存按钮为“保存这次体验”，保存后显示“这一顿已记下 / 已留下这次真实体验 / 回到发现”。
- [ ] 搜索失败、共同地图查询失败、定位不支持、定位被拒绝、照片上传失败均显示中文提示。
- [ ] 从地点详情进入“再记一顿”时，选择“一样，保留上次观点 / 有变化，更新我的观点”，后续成功态为“这一顿记好了 / 回到地点详情”。

## 8. P04｜地点详情 `/place/[id]`

- [ ] 返回操作为“← 回到发现”；地点信息只使用行政区、商圈、地点信息等食迹自有词。
- [ ] 导航操作为“导航去这里 / 查看地图位置”，说明为“会优先打开设备中的地图应用；未安装时，将在网页中打开。”
- [ ] 统计显示“小组均分 / 人留过记录 / 人愿意推荐”；新地点显示“已有朋友推荐；更多感受会在后续记录中补充。”。
- [ ] 体验汇总显示“有 N 位朋友留下感受”；没有记录显示“还没有人留下感受。”。
- [ ] 作者可见“删除这次记录”，进行态为“正在删除…”并有二次确认；管理操作仍使用“隐藏 / 确认隐藏 / 取消”。
- [ ] 删除照片、删除到访、隐藏内容和权限错误均不显示底层错误文本。

## 9. P05｜饭后聊 `/activity`

- [ ] 标题为“吃过以后，留下几句话。”，引导为“每一条，都是一位成员的真实感受。”。
- [ ] 动态地点名、昵称、笔记、推荐菜、日期和相对时间均使用功能字体并能在 320 px 换行。
- [ ] 空状态为“还没有新的饭后聊 / 新的到访记录会显示在这里。”。

- [ ] 页面标题为“我的”，身份文案为“当前身份：Owner/Admin/Member”。
- [ ] 个人区显示“我的记录 / 我去过 / 已记录 N 家”和“下回吃 / 已保存 N 家”；空状态和链接分别为“还没有记下过一顿饭。/ 记下第一顿”和“在发现里保存下次想去的地方。/ 去发现”。
- [ ] 安装区覆盖已安装、微信、iOS、可安装和普通浏览器五种状态；重点检查“食迹已安装”“请在浏览器中打开”“添加到 iPhone 主屏幕”。
- [ ] 管理员可看到“补充地点信息”和系统整理说明；邀请字段为“可加入人数”，一次性链接提示为“此链接只显示一次，请立即复制：”。
- [ ] 邀请空状态为“还没有生成邀请链接。”；复制失败提示可读。
- [ ] Owner 成员区的 Owner/Admin/Member 说明、成员状态“正常使用 / 暂停使用 / 已移除”和操作“暂停使用 / 恢复使用”正确。
- [ ] 数据导出说明逐字包含“下载包含地点、到访记录和当前偏好的 JSON 文件。照片文件不会下载，只会列出文件清单。”，Owner 操作为“导出共同地图”。
- [ ] 退出共同地图前后果说明与定稿一致，并确认不会误删地点、笔记、照片和体验。
